# 星云 · 数字孪生智慧沙盘

一个**纯前端、零后端、离线可用**的大型数字孪生集成沙盘，把智慧城市、智慧交通、智慧能源、智慧园区四大子系统融合进同一个 3D 场景，实时联动模拟、可交互操作、带数据可视化看板。

## 快速开始

- **双击 `index.html` 即可运行**（Three.js 已本地化在 `lib/` 目录，无需联网、无需安装任何依赖）。
- 也可以在本目录执行 `python -m http.server 8000` 后访问 `http://localhost:8000`。
- 部署到 GitHub Pages：把整个目录上传到仓库并开启 Pages 即可。

## 功能总览

### 四大子系统（统一地图，可一键切换视角）
- **智慧城市**：城市 CBD 建筑群、双子地标塔，夜晚自动亮起暖色楼灯
- **智慧交通**：环形 + 放射道路网、46 辆实时车流（轿车/公交）、8 处智能信号灯、公交站
- **智慧能源**：风力发电机（旋转叶片）、光伏阵列、储能站、输电塔与电网连线、能量流动粒子
- **智慧园区**：智能制造厂房、产线设备（随运行率变色）、AGV 物流小车沿园区环线行驶

### 多系统联动（每秒实时计算）
- 车流密度 + 早晚高峰 → 交通拥堵指数
- 拥堵 → 城市负荷 → 总用电需求
- 光伏（随昼夜）+ 风电（波动）+ 储能 → 清洁发电
- 供需平衡 → 园区设备运行率（供不应求时自动降产）
- 拥堵 / 清洁占比 → 碳排放

### 数据可视化
- 6 项实时 KPI（在线车辆、城市负荷、清洁发电、碳排放、设备运行率、能量流动线）
- 近 60 秒动态曲线（负荷 / 发电 / 车流 / 碳排）
- 能耗热力柱（可开关）

### 交互操作
- 拖拽旋转、滚轮缩放、左键点击任意实体查看详情
- 顶部切换五个区域视角（总览 / 城市 / 交通 / 能源 / 园区）
- 车流密度、能源需求、仿真速度滑块实时调参
- 昼夜三态切换（白天 / 夜晚 / 自动）

## 联动公式示意

```
拥堵指数 = 车辆数 × 系数 + 早晚高峰加成
城市负荷 = 基础负荷 + 拥堵 × 系数 + 夜间照明 + 需求滑块
清洁发电 = 光伏(随昼夜) + 风电(波动) + 储能释放
设备运行率 = clamp(100 − 供需缺口 × 1.2, 55, 100)
碳排放 = 拥堵 × 系数 × (1 − 0.55 × 清洁占比)
```
